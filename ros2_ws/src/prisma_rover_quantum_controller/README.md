# prisma_rover_quantum_controller

`prisma_rover_quantum_controller` is a proprietary ROS 2 Python package (previously named `quantum_controller`) that implements a reactive obstacle avoidance controller based on **fuzzy logic loaded via a Look-Up Table (LUT)**.

## Main Features

* **Reactive Obstacle Avoidance**: Subscribes to LiDAR ranges to calculate the minimum obstacle distance and its corresponding angle. If an obstacle enters a configurable "danger zone," it intercepts and overrides the linear and angular velocity commands (`cmd_vel`) generated by Nav2.
* **Dynamic LiDAR Support (2D/3D)**: Implements `lidar_listener.py` which dynamically parses either 2D `sensor_msgs/msg/LaserScan` or 3D `sensor_msgs/msg/PointCloud2` streams. For 3D clouds, it parses the direct memory buffer using NumPy to maximize performance.
* **Look-Up Table (LUT)**: Loads pre-computed fuzzy rules from LUT matrices to map combinations of obstacle `distance` and `angle` into target linear and angular velocities.

## Package Structure

* **`launch/`**:
  * `sim_controller.launch.py`: Launch script for simulation, starting the Gazebo environment, initializing localization/navigation, and running the fuzzy controller.
  * `controller.launch.py`: Starts the fuzzy obstacle avoidance node for use on the physical robot.
* **`config/`**: Contains YAML parameters for thresholds, topic remappings, and the LUT rules database.
* **`prisma_rover_quantum_controller/`**:
  * `quantum_controller_node.py`: Main ROS 2 fuzzy controller node.
  * `lidar_listener.py`: Module for subscribing and filtering 2D/3D LiDAR sensors.
  * `lut_loader.py`: Handles loading and 2D interpolation of the LUT rules.
  * `quantum_goal_generator.py`: Generates local coordinate waypoints.

## Key Dependencies

* `rclpy`, `sensor_msgs`, `geometry_msgs`, `std_msgs`
* `numpy` (matrix operations and pointcloud parsing)
* `scipy` (for 2D/3D interpolation of LUT cells)

## How to Use

The package is active under the `quantum` and `full` Docker profiles. To compile and launch:

```bash
# Compilation
colcon build --packages-select prisma_rover_quantum_controller

# Launch the fuzzy controller in simulation
ros2 launch prisma_rover_quantum_controller sim_controller.launch.py launch_sim:=true namespace:=prisma_rover
```
